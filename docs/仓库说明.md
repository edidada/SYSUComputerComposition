# 仓库说明

本仓库是中山大学计算机学院 2022 级《计算机组成原理》（周杰英老师）课程的**个人课程资料归档**，包含理论作业、实验报告、Vivado/Verilog 实验源码，以及配套的 PDF、Word 版本与图片。

> 仅供学习参考。原作者明确提醒：千万不要抄袭，发布版报告禁止转载及大篇幅复制。

## 这个仓库在做什么

课程以 MIPS CPU 设计为主线，从基础逻辑门逐步推进到单周期 CPU、多周期 CPU 与乘法器。README 中列出的重点实验如下：

- 第三次实验：四位二进制数加法
- 第四次实验：流水灯
- 第五次实验：单周期 MIPS CPU
- 第六次实验：多周期 MIPS CPU
- 第七次实验：乘法器

流水线 MIPS CPU 未实现。据原作者说明，该学期完成「多周期 CPU + 乘法器」即可取得相当于完成流水线的实验分数。

## Verilog 工程一览

每个工程对应一次实验，目录内是该实验的全部模块源码与引脚约束。

| 工程目录 | 主要内容 | 对应实验 |
| --- | --- | --- |
| `AndLogic` | 基础与逻辑门 | 早期基础实验 |
| `ButtonCounter` | 按键消抖、时钟分频、计数与七段码显示 | 基础外设实验 |
| `FluentLight` | 流水灯（含方向控制与显示） | 第四次实验 |
| `FourDigitPlus` | 四位二进制加法（ALU、多路选择器、显示） | 第三次实验 |
| `SingleCPU` | 单周期 MIPS CPU：ALU、寄存器堆、指令/数据存储器、控制器、PC 等 | 第五次实验 |
| `MultiCPU` | 多周期 MIPS CPU：在单周期基础上拆分流水级 | 第六次实验 |
| `Multiplier` | 乘法器：外部输入、运算与显示 | 第七次实验 |

## 持续集成

仓库配置了两个 GitHub Actions 工作流：

- `markdown-lint.yml`：使用 markdownlint-cli2 按 `.markdownlint.json` 校验全部 Markdown 文档。根目录与 `发布版/` 各有独立配置，规则已针对课程报告的既有写法做过放宽。
- `verilog-lint.yml`：安装 Icarus Verilog 后按工程目录逐个做 Verilog 语法检查。该任务设为非阻断，真实的源码问题以警告注解呈现，不会让整个运行变红。

目前 `SingleCPU/SingleCPU.v` 中控制器实例化的端口与控制模块定义不一致，属于已知的设计接口问题，会在 Verilog 检查中以警告形式出现。
